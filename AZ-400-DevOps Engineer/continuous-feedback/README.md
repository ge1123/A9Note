## 學習大綱

### Azure Monitor 與 DevOps 工具整合

- 能整合 Azure Monitor／Logs 與 DevOps 工具
- 能定義從 telemetry 到 issue、通知或處理流程
- 能確認 workspace、權限、保留與成本範圍

### Telemetry 蒐集策略

- 能為 Application Insights、VM、Container、Storage 與 Network 選擇適當監控
- 能區分 metrics、logs、traces 與 events
- 能避免遺漏關鍵訊號或蒐集過量資料

### Dashboard、Metrics 與 Queries

- 能建立反映工作流程與系統健康的 dashboard
- 能為開發、測試、交付與營運選擇指標
- 能配置 GitHub Insights 或相關 charts

### Pipeline Health 與最佳化

- 能監控 failure rate、duration 與 flaky tests
- 能依成本、時間、效能與可靠性最佳化 pipeline
- 能設計 concurrency 與 retention 策略

### Application Insights、Tracing 與 KQL

- 能分析 usage 與 application performance metrics
- 能查看 distributed tracing
- 能以基本 KQL 查詢 logs 並解釋結果

### Alerts、知識分享與持續改善

- 能設定 GitHub Actions／Azure Pipelines event alerts
- 能以 Wiki、Markdown、Mermaid 或 Teams 分享知識
- 能把 incident、retrospective 與使用者回饋轉成改善項目
