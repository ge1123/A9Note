## 學習大綱

### DevOps 轉型與團隊協作

- 理解 DevOps 的人員、流程與產品三個面向
- 能規劃轉型團隊、共同目標與改善週期
- 能比較 GitHub 與 Azure DevOps 在團隊中的角色

### 工作流程與回饋循環

- 能以 GitHub Flow 或 Azure Boards 設計工作流程
- 能設定 issue、通知與回饋循環
- 能連結 GitHub Projects／Azure Boards 與 repository

### 追蹤性、流程指標與查詢

- 能追蹤需求、bug、品質至 commit、PR、build 與 release
- 能解釋 lead time、cycle time 與 time to recovery
- 能為規劃、開發、測試、交付與營運設計指標或查詢

### Branching 策略

- 能比較 trunk-based、feature branch 與 release branch
- 能依團隊與發行需求選擇 branching strategy
- 能說明 GitHub Flow 與 fork workflow

### Pull request 與合併治理

- 能建立 pull request review workflow
- 能設定 branch policy 或 branch protection
- 能限制合併方式並設計必要檢查

### Repository 規模、權限與復原

- 能比較 monorepo 與 multi-repo
- 理解 Git LFS、git-fat、Scalar 與跨 repository 分享
- 能設定 repository permissions 與 tags
- 能使用 Git 復原或移除特定資料

### 文件與工具整合

- 能使用 Wiki、Markdown 與 Mermaid 記錄專案
- 能建立 release notes 與 API documentation
- 能從 Git history 自動產生文件
- 能以 webhook 或 Teams 整合 DevOps 工具

### 技術債、程式品質與 Inner Source

- 能辨識並量化技術債與 code quality
- 能規劃有效 code review
- 能說明 Inner Source 與 fork workflow 的應用
