- 能建立及設定 backup policy
- 能執行 Azure Backup backup operation
- 能執行並驗證 Azure Backup restore operation
- 能為 Azure resources 設定 Azure Site Recovery
- 能執行或演練 secondary-region failover
- 能設定及解讀 backup reports 與 alerts
