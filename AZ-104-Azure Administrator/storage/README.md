## 學習大綱

- 能建立及使用 shared access signature（SAS）tokens
- 能設定 stored access policies
- 能管理 storage account access keys
- 能設定 Azure Files identity-based access
- 能建立及設定 storage accounts
- 能設定 Azure Storage redundancy
- 能設定 object replication
- 能設定 storage account encryption
- 能使用 Azure Storage Explorer 與 AzCopy 管理資料
- 能建立及設定 Azure Files file share
- 能建立及設定 Azure Blob Storage container
- 能設定 storage tiers
- 能設定 blobs 與 containers 的 soft delete
- 能設定 Azure Files snapshots 與 soft delete
- 能設定 blob lifecycle management
- 能設定 blob versioning
- 能依最小權限、網路邊界、復原需求與成本選擇儲存設定
