## 學習大綱

- 能建立及設定 virtual networks 與 subnets
- 能建立及設定 virtual network peering
- 能設定 public IP addresses
- 能設定 user-defined routes
- 能排解 network connectivity
- 能建立及設定 network security groups（NSGs）與 application security groups
- 能評估 NSG effective security rules
- 能實作 Azure Bastion
- 能設定 PaaS service endpoints
- 能設定 PaaS private endpoints
- 能設定 Azure DNS
- 能設定 internal 或 public Azure Load Balancer
- 能排解 Azure Load Balancer
