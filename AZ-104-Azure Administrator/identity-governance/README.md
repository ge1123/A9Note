## 學習大綱

- 能建立 Microsoft Entra users 與 groups
- 能管理 user 與 group properties
- 能管理 Microsoft Entra licenses
- 能管理 external users
- 能設定 Self-Service Password Reset（SSPR）
- 能管理 Azure built-in roles
- 能在正確 scope 指派 Azure roles
- 能解讀 access assignments
- 能實作及管理 Azure Policy
- 能設定 resource locks
- 能套用及管理 resource tags
- 能管理 resource groups
- 能管理 subscriptions
- 能使用 alerts、budgets 與 Azure Advisor recommendations 管理成本
- 能設定 management groups
- 能區分 Microsoft Entra roles 與 Azure RBAC roles
