## 學習大綱

### 第一次完整 Practice Assessment

- 在不中斷查資料的情況下完成一次評量
- 保存完成畫面與總分證據
- 記錄作答日期與使用語言

### 依考綱領域分析結果

- 依五大 skills measured 分類錯題
- 分辨知識不足、誤讀題意與操作經驗不足
- 列出優先補強領域

### 錯題回溯與補強

- 把每個弱項連回對應 Issue／comment
- 重新閱讀官方文件或完成相關實作
- 用自己的話說明原答案錯誤原因

### 第二次評量與差異

- 完成複習後再次執行完整評量
- 比較兩次結果與弱項變化
- 記錄仍需處理的考點
