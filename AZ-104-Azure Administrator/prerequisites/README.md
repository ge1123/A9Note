## 學習大綱

- 能使用 Azure Portal 與 Cloud Shell
- 能辨識 Azure CLI 與 Azure PowerShell 的基本管理情境
- 能說明 tenant、management group、subscription、resource group 與 resource 的範圍關係
- 能讀取 ARM Template，並理解 parameters、variables、resources 與 outputs
- 能說明 ARM Templates 與 Bicep 的用途及基本部署流程
- 確認具備 Azure 管理所需的基本作業系統觀念
- 確認具備 IP addressing、routing、DNS 與連線診斷的基本網路觀念
- 確認具備伺服器管理、存取與維護的基本觀念
- 確認具備虛擬機器、hypervisor、資源配置與可用性的基本虛擬化觀念
